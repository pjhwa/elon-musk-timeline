# Event inclusion rubric · 이벤트 선별 기준

## 목적

“반박의 여지가 없는” 타임라인은 **주장의 강함**이 아니라 **검증 가능성**에서 나옵니다.  
이 문서는 어떤 사건을 넣고, 어떻게 쓰며, 무엇을 빼는지 고정합니다.

## 포함 (Include)

다음을 **모두** 만족하거나, (1)+(2)를 강하게 만족하면 포함:

1. **공공성:** 출생, 학위, 시민권, 법인 설립/인수, 상장, 계약, 발사 성공, 행정명령 등 기록이 남는 행위
2. **교차 검증:** Tier A 1곳 **또는** Tier B 2곳 이상 일치
3. **전기 이해에 기여:** 생애 궤적·산업 전환·역할 변화 중 하나 이상

### 우선순위

| Code | 의미 | UI |
|------|------|-----|
| **P0** | 메인 척추 — 빼면 논리가 끊김 | 기본 표시 |
| **P1** | 권장 세부 — 맥락·확장 | P0+P1 모드 |
| **P2** | 선택 (v1 미수록 또는 최소) | — |

## 제외 (Exclude)

- 평가(“천재”, “사기”, “영웅”)
- 동기 해석(“~하려고”, “~때문에 배신”)
- 미확정 루머, 단일 SNS 주장
- 미래 예측(화성 연도 등) — 목표가 공식 발표여도 **예측 라벨** 없으면 제외
- 자녀 개별 이름 전부 나열 (사생활·변동성)

| 확정 순자산 | “기사 시점 추정치” + 출처 |
